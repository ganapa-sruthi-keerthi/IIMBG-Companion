# IIMBG-Companion

> A mobile-first static web app for IIM Bodhgaya HHM students — daily class schedules, mess menu, and exam dates. No backend, deploys on GitHub Pages.

## ✨ Features

- **🏠 Home** — Live class status (● LIVE / Upcoming / Done), auto "caught up" message, tomorrow preview
- **🍽️ Food** — 7-day mess menu with day selector
- **📝 Exams** — Mid-term, End-term, Quiz dates with countdowns + holidays

## 🛠️ Tech

HTML5 · CSS3 · Vanilla JS · GitHub Pages
